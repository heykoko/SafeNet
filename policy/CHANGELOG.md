# Policy changelog

One entry per policy version. Link each change to the evaluation evidence
that prompted it, such as a disagreement row, a calibration finding or a
consistency failure, so the revision history doubles as the "what went
wrong" record.

## Template

```
## vN — YYYY-MM-DD

### Why
- Evidence: eval/reports/report_vN-1.md, disagreement ids …

### Changed
- CLAUSE-ID: what changed in the definition / allowed / disallowed / edge cases

### Added / Removed
- …

### Expected effect
- Which metric should move, and in which direction

### Actual effect (fill in after re-running the eval)
- See eval/reports/compare_vN-1_vs_vN.md
```
